# BTC 日线策略（现货、只做多、$10,000、最大亏损 30%）— V2 定稿

> 数据：Coinbase BTC-USD 日线 2018-06 → 今（正式分析自 2019-01-01）。历史规律 ≠ 未来保证。

## 0. 开发过程（V1 → V2）

关键发现：
- **机器学习无效**：对"未来 10 日涨跌"的样本外命中率 48%，低于 52% 的基准。K 线特征里没有机器可挖的额外信息。
- **F2 是唯一"稳健 + 达标"的家族**：6 个滚动年份里选中的参数几乎完全相同，全面优于 V1。
- **反转 K 线、RSI 超买、季节性**：研究阶段已证明无效，未进入任何家族。

## 1. V2 交易规则（全部机械化）

**每天 UTC 收盘后（北京时间 08:00 后）计算一次，只用已收盘日 K。**

### 1.1 趋势强度 s（−1 ~ +1）
6 个分量各自除以波动做标准化，再过 tanh(z/2) 压缩，取平均：
1. (收盘 − EMA21) ÷ ATR14
2. (EMA21 − EMA55) ÷ ATR14
3. (收盘 − SMA200) ÷ (3×ATR14)
4. 20 日涨幅 ÷ 20 日波动
5. 60 日涨幅 ÷ 60 日波动
6. MACD 柱 ÷ ATR14

### 1.2 原始仓位 = min(100%, 1.5 × s)，s ≤ 0 时为 0
仓位与趋势强度成正比：趋势越强仓位越重，转弱时连续减仓，不等"死叉"。

### 1.3 波动率缩放：× min(1, 40% ÷ 20 日年化波动率)，四舍五入到 5%
### 1.4 调仓阈值：目标与当前仓位差 ≥10% 权益才交易
### 1.5 回撤熔断（按你账户权益高点）
| 权益回撤 | 仓位上限 |
|---|---|
| ≥10% | 75% |
| ≥15% | 50% |
| ≥20% | 25% |
| ≥25% | **0%（清仓熔断）** |

熔断后只有离散趋势分回到 **6/6** 才重启（重启时权益高点重置）。
**账户红线：权益 < $7,000（−30%）→ 全部卖出并停止。**

## 2. 该有的预期
- 样本外（2021–2026）：CAGR ≈12%，最大回撤 ≈19%，Sharpe 0.73，平均仓位仅 22%，年均调仓约 58 次
- 全程 2019–2026：$10k → $47.8k（CAGR 22.4%，含 2019–20 训练期），最大回撤 −23.1%
- 牛市只吃到买入持有约 1/3~1/2 的涨幅；代价换来的是把 −77% 的回撤压到 −20% 左右
- 单日大跌会触发较大幅度减仓（如 −6% 日 → 仓位约减半），这是回撤低的原因，也是"来回被扫"的来源

## 3. 每天怎么用
```bash
cd ~/btc_quant
python3 daily.py                       # ① 每天 08:00 后运行，看"今日操作"和"明日情景"
# ② 去交易所按金额市价执行
python3 daily.py --done --price 84500  # ③ 记录成交价，账本自动更新
```
其他：`--init 10000` 初始化；`--set --cash C --btc B` 手动校正；`--no-fetch` 离线。

## 5. 风险声明
不是投资建议；极端跳空可能击穿熔断直接触及红线；交易所风险、滑点、更高手续费都会侵蚀结果；只投入亏光也不影响生活的钱。
